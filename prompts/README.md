# 提示词案例库

来自《我在拉伸店当卧底》制作中的真实反馈：3组生图、3组视频，每组都写失败现象、修订方式和验收结果。

| 类型 | 案例 | 主要经验 |
|---|---|---|
| 生图 | [I01 出门与场景连续性](I01_出门与场景连续性.md) | 朝向写到身体和脚；背景错误必须指明区域 |
| 生图 | [I02 左右手与证书墙](I02_左右手与证书墙.md) | 人物左右与画面左右同时定义 |
| 生图 | [I03 柜台内外反打](I03_柜台内外反打.md) | 机位决定背景，不给所有角度复用同一背景描述 |
| 视频 | [V01 明星脸与反派表演](V01_明星脸与反派表演.md) | 用具体五官动作代替抽象气质 |
| 视频 | [V02 邀请变成讨好](V02_邀请变成讨好.md) | 固定身体重心、视线和递卡终点 |
| 视频 | [V03 入场重复人物](V03_入场重复人物.md) | 一镜只做必要动作，明确画外人物 |

**怎么用**：先看案例判断，再读对应原文；换成当前镜头真实人物、服装、空间、台词和时长，配上正确的参考图。名字不是身份锁，单靠文字无法复现原角色。

“成功”指这一轮结果获得用户认可，不代表提示词能稳定复现。原因部分是结合反馈的分析，不是模型内部机制的证明。视频例来自Seedance 2.0 Mini；生图使用当时ChatGPT内置图片工具，未将具体引擎版本作为已知事实。

这些是历史案例，不是可直接送入生产的默认参数。尤其V01仍出现角色名字和抽象词，保留原样是为了真实对照；新镜头遵循[当前提示词规范](../docs/PROMPTS.md)，用外观与位置识别人物。成功例也不意味着应该保留每一条限制或固定机位。

只附文本，不上传演员图片、视频、账户记录或API密钥。原文中的image1/image2等指原任务附件顺序，使用时必须重新配图。
